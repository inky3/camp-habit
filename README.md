# Camp Habit

A pixel-art habit game for friends: finish real habits, earn coins, grow your island, and compete on a weekly leaderboard.

- Static site (no build step): `index.html`, `sw.js`, `manifest.webmanifest`, `vendor/supabase.js`, `icons/`
- Backend: Supabase (auth, database, server-side game rules)
- Hosting: Vercel, deploys automatically on every push to `main`
